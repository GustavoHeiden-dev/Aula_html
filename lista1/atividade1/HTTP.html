Atividade 3: O Protocolo HTTP na Web

Entendendo a comunicação entre cliente e servidor através de requisições e respostas.

1. O Papel do HTTP na Comunicação

O HTTP (Hypertext Transfer Protocol ou Protocolo de Transferência de Hipertexto) é o protocolo fundamental da World Wide Web. Ele define o formato e a maneira como as mensagens são transmitidas e formatadas, permitindo que navegadores (clientes) e servidores web entendam-se perfeitamente e troquem páginas HTML, imagens, vídeos, estilos CSS e dados em geral.

2. Conceitos-Chave: Cliente, Servidor, Requisição e Resposta

A arquitetura da Web baseia-se no modelo Cliente-Servidor:

  • Cliente: É o dispositivo ou software (geralmente o seu navegador web, como Chrome, Firefox ou Safari) que inicia a comunicação solicitando um recurso.
  • Servidor: É o computador potente ou sistema centralizado que armazena os arquivos dos sites, processa regras de negócio e devolve o que foi pedido.
  • Requisição (Request): A mensagem enviada pelo cliente ao servidor pedindo uma ação ou arquivo específico.
  • Resposta (Response): O pacote de dados enviado de volta pelo servidor para o cliente, contendo o resultado da requisição (como o código da página ou uma mensagem de erro).

3. Principais Métodos HTTP: GET e POST

Os métodos (ou verbos) HTTP indicam a intenção da requisição feita pelo cliente:

  • GET: Utilizado para solicitar a recuperação de um recurso (como carregar uma página web ou imagem). Os dados enviados ficam visíveis na URL. É seguro e idempotente (fazer várias vezes produz o mesmo efeito).
  • POST: Utilizado para enviar dados a serem processados por um servidor (como preencher um formulário de cadastro, enviar uma senha ou fazer upload de arquivos). Os dados trafegam ocultos no corpo da requisição.

4. Exemplo de uma Requisição HTTP

Abaixo está um exemplo real de mensagem enviada por um navegador ao solicitar a página inicial de um site:

GET /index.html HTTP/1.1
    Host: www.exemplo.com.br
    User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)
    Accept: text/html,application/xhtml+xml
    Accept-Language: pt-BR,pt;q=0.9

5. Exemplo de uma Resposta HTTP

Abaixo está o retorno gerado pelo servidor web ao atender com sucesso a requisição acima:

HTTP/1.1 200 OK
    Date: Tue, 03 Jun 2026 12:00:00 GMT
    Content-Type: text/html; charset=UTF-8
    Content-Length: 125


        


    
        
6. Códigos de Status HTTP

        
Os códigos de status são números de três dígitos retornados pelo servidor para indicar o resultado da requisição. Abaixo estão 6 dos códigos mais importantes:


        

            
                

                    Código
                    Status
                    Explicação
                

            
            
                

                    200
                    OK
                    A requisição foi bem-sucedida e o servidor retornou o recurso solicitado.
                

                

                    301
                    Moved Permanently
                    O recurso solicitado foi movido permanentemente para uma nova URL (redirecionamento).
                

                

                    400
                    Bad Request
                    O servidor não conseguiu entender a requisição devido a uma sintaxe inválida enviada pelo cliente.
                

                

                    403
                    Forbidden
                    O servidor entendeu o pedido, mas se recusa a autorizá-lo (falta de permissão de acesso).
                

                

                    404
                    Not Found
                    O servidor não encontrou o recurso solicitado (página ou arquivo inexistente).
                

                

                    500
                    Internal Server Error
                    Erro genérico no servidor. Indica que algo inesperado deu errado nos bastidores do sistema.
